# Try it: free sites where you practise in the browser

Learn cards ask you to **try** each new idea for 15 to 20 minutes. These free sites let you do that in a browser, with nothing to install.
Every address was checked on 24 November 2026 and opened with status 200.
A site that needs an account says so in its row. Never pay for anything: every site here has a free use that is enough for the course.

## Dart and Flutter

| Site | Address | Use it for |
|---|---|---|
| DartPad | https://dartpad.dev | Run Dart and small Flutter apps in the browser. Start from the **Samples** menu. See [`setup/day1.md`](setup/day1.md) |
| Dart language tour | https://dart.dev/language | Every page has short examples; paste them into DartPad and change them |
| Dart codelabs | https://dart.dev/codelabs | Guided exercises (null safety, async, collections) that run in the page |
| Your first Flutter app (codelab) | https://docs.flutter.dev/get-started/codelab | Google's step-by-step first app |
| Widget catalogue | https://docs.flutter.dev/ui/widgets | Find the widget for a job: layout, lists, input, buttons |
| Exercism Dart track | https://exercism.org/tracks/dart | Short practice problems with tests, and free mentor feedback. Needs a free account |
| Flutter Gems | https://fluttergems.dev/ | Browse packages by job when you want to see the options. Pick packages from pub.dev and the course's `VERSIONS.md` |

| Site | Address | Use it for |
|---|---|---|
